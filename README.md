# Legal Office Management System - Backend

Backend REST API for the **Legal Office Management System**.

This system is designed to help a legal office manage legal files, documents, proof of service, user accounts, and registration approval.

The backend is built using **Java Spring Boot** and provides secure REST APIs consumed by the Angular frontend.

---


## 🚀 Project Overview

The Legal Office Management System provides functionality for:

- User registration
- Administrator approval of user registrations
- User login
- JWT authentication
- Role-based authorization
- Legal file management
- File actions and tracking
- Document management
- Proof of service management
- Status and workflow tracking
- Secure REST API communication
